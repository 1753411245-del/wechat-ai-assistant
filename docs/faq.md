# FAQ

**Q：会不会封号？**
本项目不注入进程、不改微信文件，只是"读本地数据库 + 模拟人手操作窗口"。
风险低于 hook 类方案，但不是零。建议：先小号跑、别群发、别高频、回复内容别带敏感词。

**Q：能回复新加的好友吗？**
能。`WXAI_AUTO_PRIVATE=1` 时会自动接管所有私聊（含新好友）。
不想全接管就只填 `WXAI_WATCH` 白名单。

**Q：群消息为什么只回 @？**
不 @ 全回会在活跃群里刷屏，很容易被踢或被限制。`WXAI_AT_ONLY=1` 是默认建议值。
`WXAI_AT_NAME` 填你在**该群里的昵称**（可能与账号昵称不同），不确定就跑
`python src/peek.py <群 id>` 看真实 @ 文本。

**Q：语音能转文字吗？**
不做。语音正文是 XML + 音频资源，转文字要接 ASR 服务。当前策略是回一句提示
（`WXAI_HINT`），让对方打字。

**Q：AI 会乱报价钱吗？**
人设里已经写了"价格/库存/承诺不要自己编"，并在系统提示里要求不确定时打 `[[NEED]]` 标记。
带标记的回复会被剥掉标记、并单独推送一条"需要你接手"给你。
但**模型不能 100% 可靠**，关键业务请自己复核，或把 `WXAI_PERSONA` 改成只做"转达"。

**Q：能多开/多账号吗？**
可以。`config.env` 里用 `WXAI_ACCOUNT` 指定账号，或用 `WXAI_DB_DIR` 指定数据目录。
不同账号建议各自放一份项目目录，互不干扰。

**Q：支持 macOS / Linux 吗？**
不支持。发送依赖 Windows UIA；读库部分跨平台，但本项目按 Windows 交付。

**Q：微信升级后还能用吗？**
读库部分对版本不敏感；UIA 部分依赖 `wechatauto-replica`，微信界面大改时需要更新它。

**Q：会不会把我电脑上的聊天记录上传？**
不会。除了发给模型的**当前这一条消息文本**（以及你配置的人设），
没有任何聊天内容离开本机；数据库读取全部在本地完成。
